# 気象予報士 学科過去問トレーニング

気象予報士試験(学科)の過去問題を、ブラウザだけで演習できる無料の学習アプリです。
インストール不要・登録不要・広告なし・完全オフライン対応(PWA)。

**▶ アプリを開く: https://maimmaim20230728-blip.github.io/kisho_exam_web/**

## 収録内容(全300問・全問に解説付き)

- 第56回(2021年8月)〜第65回(2026年1月)の学科試験 10回分
- 予報業務に関する一般知識 15問+専門知識 15問 × 10回=300問
- 全問にやさしい言葉の解説(むずかしい用語はタップで説明がポップアップ・ルビつき)

## 機能

- 本試験モード(回ごとに15問通しで解いて採点・合格目安11問の表示)
- ランダム演習/間違えた問題だけの復習/解説だけを読む閲覧モード
- 用語辞書1746語(タップでポップアップ・ふりがなつき)・夜間モード
- 学習記録は端末内(localStorage)にのみ保存されます

## 出典・利用について

- 問題文・図表は **一般財団法人 気象業務支援センター** の気象予報士試験 過去問題です。
  同センター試験部に連絡のうえ、案内された条件に従って掲載しています(2026年9月)。
  全ての問題に出典(実施回)を明記しています。
- **解説は本アプリが独自に作成したものです。気象業務支援センターとは無関係であり、
  内容は当団体の責任によるものです。**
- 過去の試験問題は、技術の進展や法規改正等により、現在では解答が変わる可能性があります。
  各問題の出典(実施回)をご確認ください。
- 市販書籍などからの引用を含む一部の図は、本アプリでは表示していません(該当問題には
  その旨の注記を表示し、気象業務支援センター公開の問題冊子をご案内しています)。
- 誤りを見つけた場合はIssueでお知らせください。速やかに修正します。
